# 2026-11-07

## chrome-extension (new, v0.1.0)

- Added `chrome-extension/`: Manifest V3 port of `firefox-extension/` with the
  same bridge protocol, command router, content-script actions and popup.
- Differences: service-worker keepalive (WS ping every 20 s + `alarms`),
  `scripting.executeScript`, `sendResponse` messaging, `chrome.action`, and
  response-body capture via fetch/XHR hooks in `injected.js` (MAIN world).
- Server unchanged. Verified only with `node --check` + JSON validation; not yet
  tested in a live Chrome.

## Docs

- Added `chrome-extension/README.md`; updated root `README.md` and `NOTE.md`
  (ADR + current state).

## mcp-server v0.2.2 (PyPI release)

- Bumped server version `0.2.1` -> `0.2.2` (`mcp-server/pyproject.toml`,
  `src/firefox_browser_mcp/__init__.py`). Patch release; no code changes — the
  PyPI README now mentions the `chrome-extension/` companion.
- Release flow: all edits + commit BEFORE build/upload; built outside the repo
  with `uv build --out-dir /tmp/...`, `twine check`, upload via `~/.pypirc`
  (token never written to the repo).
